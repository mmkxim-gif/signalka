# 04. CAN: Camry XV40

Настройка относится к Toyota Camry XV40 2009, 2.4 л, АКПП, штатный ключ. Она не заменяет актуальную карту установки: не указываются точки подключения и распиновка, поскольку они должны быть подтверждены для конкретного автомобиля.

## Проверка статусов

В StarLine Master выберите подтверждённую конфигурацию автомобиля и откройте доступную диагностику CAN. При включённом питании автомобиля изменяйте по одному состоянию и сверяйте индикацию:

| Проверка | Ожидаемая логика |
| --- | --- |
| Зажигание | меняется только при соответствующем положении ключа |
| Двигатель | появляется только после устойчивого запуска |
| Обороты | отображаются правдоподобно и меняются с работой двигателя |
| Двери | каждая открытая дверь отображается корректно |
| Капот | открытие капота определяется до испытаний автозапуска |
| Багажник | открытие багажника определяется корректно |
| Тормоз | нажатие педали меняет статус |
| `P/R/N/D` | положение селектора соответствует фактическому положению |
| Центральный замок | команды и фактическое состояние не противоречат друг другу |
| Напряжение | значение правдоподобно при выключенном и работающем двигателе |

Работу двигателя для проверки выполняйте только при безопасных условиях. Не запускайте автозапуск, пока не подтверждены `P`, капот, тормоз и двигатель/обороты.

## Если статусы неверны

1. Не компенсируйте ошибку отключением защит или произвольным изменением параметров.
2. Сверьте год, кузов, двигатель, АКПП и тип ключа с выбранной конфигурацией и актуальной картой установки/StarLine Master.
3. Проверьте питание, массу, целостность разъёмов и фактическое CAN-подключение по карте установки, не меняя распиновку наугад.
4. Сопоставьте проблему с версией ПО блока и CAN; при необходимости примените официально рекомендуемое обновление.
5. Если статус по CAN не поддержан или нестабилен, согласуйте безопасное решение с квалифицированным установщиком. Затем повторите весь протокол проверки.
