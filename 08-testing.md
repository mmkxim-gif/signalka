# 08. Итоговый протокол проверки

Проводите тесты на открытой площадке. Автозапуск проверяйте только после успешного штатного запуска ключом и корректных защитных статусов.

| Раздел | Проверка | Результат / примечание |
| --- | --- | --- |
| Блок | Надёжно закреплён, разъёмы защёлкнуты, нет нагрева/запаха/ошибок предохранителя | ____ |
| StarLine Master | Новый блок определяется; версии ПО и CAN зафиксированы; конфигурация сохранена защищённо | ____ |
| CAN | Зажигание, двигатель, обороты, двери, капот, багажник, тормоз, `P/R/N/D`, ЦЗ и напряжение проверены | ____ |
| Штатный ключ | Зажигание, запуск и остановка двигателя работают штатно | ____ |
| Центральный замок | Закрытие/открытие и индикация соответствуют фактическому состоянию | ____ |
| Иммобилайзер | Штатная защита сохранена; обучение обхода подтверждено актуальной процедурой | ____ |
| Автозапуск | Один безопасный запуск, устойчивые обороты, корректная остановка и защитные запреты | ____ |
| GSM | Есть регистрация в сети и передача данных; секреты не зафиксированы в отчёте | ____ |
| StarLine 2 | Новый блок зарегистрирован; статусы и разрешённые команды проверены | ____ |
| GPS (если есть) | Координаты доступны и правдоподобны | ____ |
| Финал | Панели собраны, жгуты закреплены, владелец проинформирован о результате | ____ |

Зафиксируйте дату, обезличенные версии ПО и результаты. При любом «не пройдено» не маскируйте проблему отключением защит: используйте [диагностику](09-troubleshooting.md), исправьте причину и повторите связанные проверки.
