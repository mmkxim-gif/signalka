# 09. Диагностика неисправностей

Перед проверками поставьте автомобиль в безопасное состояние. Не меняйте одновременно несколько параметров и не отключайте штатный иммобилайзер, контроль капота, тормоза или селектора.

| Симптом | Проверить в первую очередь | Дальнейшие действия |
| --- | --- | --- |
| Блок не определяется | USB-кабель, питание, разъёмы, совместимость ПО | Отключите питание по процедуре, осмотрите контакты, повторите с актуальной StarLine Master; не подавайте питание на произвольные пины. |
| CAN не показывает статусы | Выбранный автомобиль, версию CAN/ПО, питание и разъёмы | Сверьте 2009/2.4/АКПП/ключ с актуальной картой установки; проверьте подключение только по ней; повторите [CAN-проверку](04-can-camry-xv40.md). |
| Не работает штатный запуск | Питание, разъёмы, штатную цепь запуска после замены | Прекратите настройку автозапуска, восстановите нормальный запуск ключом и обратитесь к квалифицированному установщику при необходимости. |
| Не работает автозапуск | `P`, капот, тормоз, запреты, обучение обхода, контроль двигателя | Исправьте неверный статус; повторите безопасный тест по [протоколу](06-autostart.md). |
| Стартер крутит, но двигатель не запускается | Обход иммобилайзера, зажигание, условия обучения | Сверьте актуальную карту/StarLine Master, проверьте штатный запуск; не делайте постоянный обход. |
| Двигатель запускается и сразу глохнет | Контроль двигателя/оборотов, зажигание, обход | Сравните статусы при ключевом и автоматическом запуске, подтвердите устойчивый сигнал оборотов. |
| Не работает GSM | Установка SIM, питание, покрытие, регистрация сети, данные | Считайте новый блок новым устройством, проверьте StarLine 2 и условия SIM без раскрытия идентификаторов. |
| Пропали отдельные функции | Экспорт старых настроек, совместимость версий, физические разъёмы | Сопоставьте «функция → подключение → статус → настройка»; переносите только подтверждённые совместимые параметры. |

Для обращения в поддержку или к установщику подготовьте обезличенный журнал: модель автомобиля, версии ПО, время, последовательность действий, наблюдаемые статусы и фото разъёмов без секретов. Не отправляйте сервисные коды, activation code, пароли, токены или данные SIM.
