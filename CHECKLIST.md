# Чек-лист замены StarLine S96 v2 — Camry XV40

Автомобиль: Toyota Camry XV40, 2009, 2.4, АКПП, штатный ключ.  
Дата: __________  Исполнитель: __________

## До работ

- [ ] Подтверждена совместимость нового S96 v2 и актуальная карта установки.
- [ ] Подготовлены StarLine Master, USB, инструмент и безопасная открытая площадка.
- [ ] Сделаны фотографии блока, разъёмов и жгутов без секретных данных.
- [ ] Сохранены защищённая копия и обезличенные сведения старого блока (если доступно).
- [ ] Автомобиль в `P`, стояночный тормоз включён, двигатель заглушен, ключ извлечён.

## Замена и настройка

- [ ] Питание отключено по документации автомобиля/карте установки.
- [ ] Старый блок снят без изменения распиновки и проводки.
- [ ] Новый блок закреплён, существующие разъёмы подключены по ключам.
- [ ] После включения нет нагрева, запаха, искрения и ошибок предохранителей.
- [ ] Новый блок определён в StarLine Master; использован сервисный код нового блока.
- [ ] Проверены ПО, CAN и выбранная конфигурация по актуальной карте/StarLine Master.
- [ ] Проверены CAN-статусы: зажигание, двигатель/обороты, двери, капот, багажник, тормоз, `P/R/N/D`, ЦЗ, напряжение.
- [ ] Обход/iKey обучен строго по актуальной процедуре; штатный запуск ключом сохранён.

## Проверка

- [ ] Штатный запуск ключом, остановка и центральный замок работают.
- [ ] Перед автозапуском подтверждены `P`, тормоз, капот, двигатель и обороты.
- [ ] Выполнен один безопасный тест автозапуска, устойчивой работы и остановки.
- [ ] Проверены SIM/GSM: сеть и данные; никакие секреты не записаны в чек-лист.
- [ ] Новый блок зарегистрирован в StarLine 2; проверены статусы/разрешённые команды и GPS (если есть).
- [ ] Итоговая конфигурация сохранена в защищённом месте, панели собраны, жгуты закреплены.
